# Data

- `trd-table-n10.csv` — the full table. Columns: `objects, arrows,
  arrow_type_semigroupoids, all_trds`. The third column excludes digraphs with an
  isolated point (the convention of arXiv:2509.00837); the fourth does not, and its
  column sums are A091073.
- `oeis-b-file.txt` — 385 terms, linear index over rows, row n running k = 1..n^2.
- `triangle-rows.txt` — the same rows in readable form.

Released under CC0: enumeration results are facts.
